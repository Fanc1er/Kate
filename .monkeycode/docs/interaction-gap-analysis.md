# 交互逻辑规范 — 现状差距评估与实施计划

> 对照《企业级安全监测后台 — 交互逻辑规范》（12 节）逐条评估 cinsight 前端现状，输出差距清单与分阶段实施计划。本评估仅涉及交互行为，不含视觉规范（视觉已在上轮完成）。

## 现状概览

当前前端交互能力有限：列表页具备基础分页（上/下一页 + 总数）、下拉筛选（select + 查询按钮）、行内文字操作按钮、loading 布尔态、4 类型 Toast、手写 Modal（各视图 `.modal-mask`）、证据抽屉（EvidenceDrawer，无滑入动效/Esc）、骨架屏组件（Skeleton.vue，7 个列表视图使用）。缺失全局搜索、键盘快捷键、表格排序、右键菜单、批量操作栏、统一 Tooltip、动效体系、响应式与无障碍。

## 分阶段实施计划

### 阶段 0（P0 · 基础交互一致化 · 高价值、通用、无形态争议）
1. 按钮状态统一：hover/active/loading spinner/disabled，建立全局按钮样式约定
2. Toast 规范对齐：四类背景色块 + 图标、堆叠 max 3、错误 5s 手动关闭、停留时长
3. Modal 二次确认统一组件：危险操作确认、遮罩可关闭、缩放动效、Danger 按钮
4. Tooltip 统一组件：300ms 延迟、深底白字、自动翻转
5. 空状态统一：插画 + "刷新" Secondary 按钮
6. 表格行 hover + 表头排序（升/降/取消）
7. 分页器完善：每页条数 10/20/50/100、页码、切换回第 1 页
8. 无障碍基础：focus outline、aria-label、prefers-reduced-motion
9. 动效基础：页面切换淡入、卡片 hover 抬升、Modal/抽屉动效

### 阶段 1（P1 · 增强交互 · 与现有功能结合）
1. 统计卡片 hover 抬升 + 点击跳详情 + 数字滚动 count-up
2. 表格整行点击跳详情 + 首列 sticky（仅列多视图）
3. 批量操作栏（全选/批量处置）
4. 搜索框防抖 + URL 同步
5. Esc 关闭弹窗/抽屉/下拉
6. 加载超时 >5s 重试
7. 面包屑（三级页面）

### 阶段 2（P2 · 需产品确认 · 形态相关）
1. 全局搜索 Cmd+K（需定义搜索范围：跨资产/漏洞/发现/告警？）
2. 三栏筛选面板（是否将现有 select 筛选升级为中栏复选面板）
3. 右键上下文菜单（行）
4. 二级手风琴菜单（是否将 13 个菜单分组，分组方案）
5. 响应式断点（是否需要移动端/平板适配）

### 建议搁置（与当前产品形态不符）
- 拓扑节点图、Sparkline 迷你状态条、在线头像、团队头像——均为「网站可用性监测 / 工作节点」产品形态，与 cinsight「安全监测」（资产/漏洞/发现/告警/事件/内容安全/工单）不匹配，除非产品方向调整。

## 需澄清项

1. **规范术语形态差异**：规范大量使用「站点/URL/状态码/可用性/重新探测/加入白名单/响应耗时/工作节点拓扑」，与 cinsight 安全监测形态不符，是否需按「安全监测」语义重新映射（如"重新探测"→"重新检测"，"白名单"→"忽略规则"）？
2. **三栏布局**：规范假定「左菜单 + 中筛选 + 右表格」三栏，当前为「左菜单 + 主内容」两栏。是否引入中栏筛选面板？
3. **响应式**：产品是否仅面向桌面端（≥1024px），可暂缓移动端适配？
4. **二级菜单分组**：13 个菜单项是否需要重组为分组（如「监测/管理」）？
